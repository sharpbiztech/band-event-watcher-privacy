BAND Event Watcher - Privacy Policy

Last updated: September 26, 2026.

BAND Event Watcher is a private Chrome extension built and used by one person, its developer. It is not offered to the public.

What it does

Every two hours, or when the owner presses a button, the extension opens the owner's own BAND chats on band.us in a background window. It reads the text of the messages and passes it to a program running on the owner's own computer. That program finds events such as practices and deadlines and adds them to the owner's own Google Calendar as pending events.

What data it handles

The extension reads chat messages and page text from band.us (personal communications and website content). It reads nothing from any other website.

Where the data goes

  • The chat text goes to a program on the owner's own computer.
  • That program sends the text to Google's Gemini AI service (Google Cloud Vertex AI), under the owner's own Google Cloud account, only to find events in it.
  • Found events are written to the owner's own Google Calendar.

The data is not sold. It is not shared with any other third party. It is not used for advertising, tracking, credit, or lending. It is used only for the single purpose above: finding events in the owner's own chats.

Storage

The extension stores only its last run time and result in the browser. The local program keeps a small record on the owner's computer so it does not add the same event twice.

The extension does not

  • send, post or change anything on BAND. It is read-only.
  • load or run any code from the internet. All its code is in the installed package.
